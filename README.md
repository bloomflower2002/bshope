BShop Navigation Bar
A responsive navigation bar with integrated search and menu functionality built with HTML, CSS, and JavaScript.

 Overview
The BShop Navigation Bar is a fully responsive, mobile-first navigation component built with pure HTML, CSS, and vanilla JavaScript. It provides a seamless user experience across all devices with intelligent search and menu interactions - all without any external dependencies or frameworks.

How It Works
Mobile View (≤ 860px):

Collapsed: Shows logo, hamburger menu icon, and language button

Expanded (click hamburger):

Search bar overlays the entire navbar (hides logo and buttons)

Navigation menu drops down below

Both open together with a single click

Click hamburger again or click outside to close everything

Desktop View (> 860px):

Full navigation links visible

Search bar with category dropdown

Language switcher

Sign In button

Features
Fully Responsive - Works on all screen sizes

Smart Search - Category filtering with real-time search

Modern Design - Gradient backgrounds with glass morphism

Accessible - ARIA labels and keyboard support

 Lightweight - No dependencies, pure vanilla JS

Interactive - Smooth animations and transitions

Easy Customization - Well-organized CSS with comments

Installation
Option 1: Direct Include
Copy the HTML structure to your page

Copy the CSS to your stylesheet

Copy the JavaScript to your script file
